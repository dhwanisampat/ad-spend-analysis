## Advertising Spend Analysis

This project is a small data analysis project where I explored how advertising spend changes over time. The goal was to understand patterns in the spending data and visualize them using simple graphs.

## Dataset

The dataset used for this project is stored in the **dataset** folder as `dataset.csv`. It contains information related to advertising spend over different days.

## What I did in this project

In this project I used Python to:

* Load and explore the dataset
* Analyze advertising spend trends
* Create visualizations to better understand the data

## Tools Used

* Python
* Pandas for data analysis
* Matplotlib for creating graphs
* Jupyter Notebook

## Graphs

The project includes a few visualizations.These graphs help in understanding how spending changes over time.

## Conclusion

Through this analysis, I was able to visualize advertising spend patterns and understand how the spending varies across different days and weeks.
